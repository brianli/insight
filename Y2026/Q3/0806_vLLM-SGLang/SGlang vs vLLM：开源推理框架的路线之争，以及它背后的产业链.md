2026年5月，一家叫RadixArk的公司拿了**1亿美元**种子轮，估值**4亿美元**。投资人名单长得吓人：Accel领投，英伟达、AMD、英特尔CEO、博通CEO全部跟了。

这家公司干什么的？维护一个叫SGlang的开源推理框架。

你可能没听过SGlang。没关系。它和另一个叫vLLM的框架，每天在全球几十万张GPU上跑着**数万亿个token**。你用的ChatGPT、Claude、Cursor代码补全，后面大概率跑着它俩中的一个。

 训练决定了一个模型能多聪明。推理决定了这个模型能多便宜地让你用上。

## 一、50字速成OS

一句话说清楚：

**vLLM**是"内存管理大师"——把显存当操作系统内存一样分页管理，浪费从60%降到4%，GPU利用率翻了几倍。

**SGlang**是"缓存复用大师"——它不扔掉请求结束后的缓存，用一棵树记住所有算过的东西，下次再来直接复用。多轮对话场景下，吞吐量可以高**3到5倍**。

一个说"我能同时接更多客人"。一个说"我能让回头客不用排队"。

## 二、技术路线分歧：显存管理 vs 调度优化

这俩框架的底层分歧，其实就一条：**怎么管那块叫KV缓存的东西。**

大模型每次推理，都要把前面算过的内容存下来——不然每生成一个字就得把整段对话重新算一遍。这块存储空间叫KV缓存，是推理的第一瓶颈。

vLLM 2023年提了个天才想法：**PagedAttention**。把KV缓存切成固定大小的小块，像操作系统的虚拟内存一样按需分配。以前一个请求就算只用10%的显存，也得整块预留——浪费60%到80%。PagedAttention把浪费压到不到**4%**。

SGlang 2024年出的**RadixAttention**，往前多走了一步：请求结束别扔缓存，用一棵"基数树"存着。下个请求来了，树里走一圈，能找到多少相同的前缀就复用多少。对于多轮对话、RAG应用——系统提示词是一样的，只是后面用户问题不同——这种方式把重复计算砍掉了大半。

打个不精确但好理解的比方：

vLLM像一个高效停车场——车位小、调度快、不浪费空地。SGlang在这个停车场里又加了一套"熟客系统"——来过的人不用重新登记。

具体到数字：Llama 3.1 8B模型跑在H100上，SGlang吞吐量约**16200 tokens/秒**，vLLM约**12500 tokens/秒**，高出**29%**。到了70B大模型，差距缩小到个位数百分比。但在前缀复用率高的场景（多轮对话、Agent调用工具），SGlang的缓存命中率能到95%以上，有效延迟降低**3到5倍**。

## 三、开源推理框架简史

2017-2022年，推理根本没人当回事。那会儿大家卷的是训练——谁的模型参数大、谁的集群GPU多。推理？顺手用训练框架跑一下就行。

2022年10月，HuggingFace推出TGI（Text Generation Inference），第一次把"推理"当成独立产品。

2023年6月，vLLM带着PagedAttention横空出世。学术论文还没发完，GitHub星已经过万。因为它解决的是最朴素的问题：**你的GPU利用率只有10%。** 部署过大模型的人都知道这意味着什么——花几百万买的H100，90%的算力在发呆。

2024年1月，SGlang从伯克利Ion Stoica实验室出来（对，就是Databricks那个Ion Stoica）。RadixAttention是它的核心创新，但更底层的逻辑是：**推理不该只是一个HTTP服务器，应该是一个编程模型**——能理解"这段话和那段话是同一个意思"。

2024到现在，两个框架进入互抄合流阶段。vLLM加了prefix caching。SGlang追了模型支持列表。2025年12月，HuggingFace把TGI送进了维护模式——开源推理框架正式进入双雄时代。2026年5月，SGlang背后的团队独立为RadixArk，拿了英伟达和AMD同时站台的钱。

而同一时间，推理市场的规模已经悄悄超过了训练——全球AI推理市场2026年预计超**1100亿美元**（Fortune Business Insights估算），推理占AI算力支出的大头已是定局。

**说个暗线——Kimi K3 的架构演进，就是推理框架需求放大的活标本。**

2019年，OpenAI 放出 GPT-2，1.24亿参数。2025年，Kimi 发布 K3，2.8万亿参数——**22580倍**。

每一步跨越，都是因为前一层的资源浪费太大了。KV Cache 解决了每次生成都要重算全文的问题。GQA（分组查询注意力）把多头注意力的 KV 头砍掉大半，显存省了一大块。MoE（混合专家）让每层只激活1/8的参数，算力省了7/8。MLA（多头潜在注意力）更进一步——把KV缓存压缩成低维向量，推理时的显存和带宽需求再砍一刀。[¹⁰]

但每次"省下来"的算力，立刻被更大的模型和更多的 token 吃掉。K2.5 到 K3，参数从 1万亿跳到 2.8万亿。用户端 token 消耗不是线性涨——是指数级。

**架构创新给了发动机，推理框架是变速箱。** SGlang 和 vLLM 就是让这些架构创新在 GPU 上高效跑起来的引擎——没有它们，MLA 的缓存压缩再聪明也落不了地。

（这条暗线的拆解来自 Baseten 工程师用了48小时逐行读 Kimi K3 源码后的分析。JackCui 公众号 2026-08-03 有详细解读。[¹⁰]）

## 四、从大模型到芯片：一条推理请求的完整旅程

说清楚框架之后，往下看一层：一个推理请求到底经过什么。

拿Llama-3-70B跑在8张H100上举例。你在对话框敲了一行字"帮我写一段Python"。按下回车。

**第一层，大模型层**：你的输入被切成token，加上系统提示词，拼成一段prompt。70B参数模型，仅加载到显存就要约140GB。

**第二层，推理框架层**：vLLM收到请求。它查一下——这个系统提示词之前有人用过吗？如果开了prefix caching，有的话KV缓存直接拿来用，只算你新增的那7个字。然后用continuous batching——不等这一批请求全部跑完，谁先结束就把空位让给新人。

**第三层，CUDA算子层**：框架不写底层计算。它调用的是FlashAttention（一种高效注意力计算）、GEMM（矩阵乘法）这些算子。框架只决定"现在调哪个算子、用什么精度、怎么排顺序"。

**第四层，芯片层**：算子在H100的Tensor Core上运行。H100的HBM带宽3.35TB/秒，80GB显存——推理的命门不是算力，是带宽。你每生成一个token，都要把整个模型参数"搬"一遍。

核心结论很简单：**推理框架不写算子，但决定调用哪个算子、怎么调用。** 它是大模型和芯片之间的翻译官。翻译得好，同样的H100能多放一半的请求。翻译得差，70B模型都跑不动。

## 五、商业模式：开源框架不赚钱？六层谁在赚钱

SGlang和vLLM都是Apache 2.0开源协议。免费。

那钱在哪？往下拆：

**框架本身**：免费。RadixArk靠1亿美元融资活着，未来可能卖托管服务。vLLM背后没有独立公司，靠社区和UC Berkeley维持。

**托管服务**：这一层不是简单的"按token收钱"——拆开看三层：

**第一层，Token 差价**。自建 GPU 集群跑推理框架，批发价买算力→零售价卖 token。毛利来自规模效应+框架优化拉高的 GPU 利用率。以硅基流动为例，毛利率约 **35-40%**（招股书推算数据）。[⁹]

**第二层，模型托管抽成**。平台接开源模型→调好 SGlang/vLLM→一键 API→按量收费。平台赚的不是 token 本身，是"省掉了客户自己部署框架+调优的人力成本"。团队花两周调框架，平台让你五分钟上线——中间的差价就是这一层。

**第三层，增值服务**。高并发 SLA 保证、私有化部署、定制算子优化→按年合同收费。毛利率远高于纯 token 差价——卖的是"不出事"和"比别人快"。这在硅基流动的招股书里对应的是政企服务收入，增速比 token 收入快三倍。[⁹]

**云厂商**：AWS、Azure、阿里云把框架打包进算力套餐。你租的不是"8张H100"，是"能跑Llama-70B的推理端点"——中间那层软件，就是vLLM或SGlang。

**芯片厂商**：这才是真正赚大钱的人。

 开源推理框架，是AI芯片的Linux。 

英伟达的H100为什么能卖3万美元？因为有一整套推理框架生态让它即插即用。而国产芯片追赶的，正是这个生态位。国产芯片和英伟达的差距，很多时候不是硬件算力差多少，是"你的芯片上能跑 vLLM/SGlang 吗？跑起来性能发挥几成？"

产业链一层一层往下推：**越靠近芯片，推理框架越像"操作系统"——不是因为它卖得贵，是因为没有它，芯片就是一块硅。**

## 六、美国上市公司

**NVIDIA**（英伟达）：推理框架的最大赢家。vLLM和SGlang都是在英伟达GPU上跑的。H100/B200/GB200——每一代新卡降价不降量，因为token消耗增速远高于单卡性能提升。英伟达的NVentures甚至同时投了RadixArk。

**Groq**：专用推理芯片。LPU架构主打确定性低延迟，拿了沙特15亿美元合同。切的是"框架优化不到的死角"——硬件层面天生快。

**Cerebras**：晶圆级推理引擎，单芯片能跑1万亿参数的模型。拿了OpenAI超百亿美元的多年供应合同。这是最极端的"跳过框架层"——芯片大到不需要调度优化。

## 八、对A股投资者的三条线索

**第一条：推理芯片的"操作系统"是谁。**

英伟达的CUDA生态就是AI时代的Windows。但中国买不到最先进的英伟达卡。所以**寒武纪**和**海光信息**不只是"国产GPU"——它们要做的，是让vLLM和SGlang在国产芯片上跑出同样的性价比。谁先做到，谁就是中国推理芯片的操作系统。

**第二条：推理框架优化≠算力需求下降。**

很多人担心：框架越优化，需要的GPU越少。逻辑反了。

前面 Kimi K3 的架构演进史就是最好的证据——KV Cache、GQA、MoE、MLA，每一代架构都在"省算力"，但省下来的每一分算力立刻被更大的模型和更多的 token 吞掉。GPT-2 到 K3，参数涨了 22580 倍——不是靠硬件堆的，是靠架构优化让每一瓦算力做更多事，然后应用端瞬间把省出来的全吃了。

这是 Jevons 悖论在 AI 时代的翻版：**优化是需求的放大器，不是抑制器。** 框架把单 token 成本打下来，应用端就用更多 token、跑更大的模型。GPU 总量逻辑只会往上走。

**第三条：盯着token，别盯着GPU。**

推理时代，核心计量单位从"张"变成了"个"——从多少张GPU，变成多少个token。**硅基流动**的招股书写得很清楚：日吞吐量万亿token，年收入从700万涨到5500万。这个增速不是一个公司的故事——是整个推理产业链的斜率。谁在token流水线上分到了最大的价值，谁就有最大的确定性。

 开源推理框架是AI时代的Linux。免费、好用、谁都能装。但搭在这之上的芯片、token平台——每一层都在重新标价。
